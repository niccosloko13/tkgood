# Product Hunter Companion

Extensão Chrome Manifest V3, somente leitura.

## Instalar

1. Abra `chrome://extensions`
2. Ative **Modo do desenvolvedor**
3. Clique **Carregar sem compactação**
4. Escolha esta pasta `extension`
5. Mantenha o painel rodando em `http://127.0.0.1:8000`
6. Abra TikTok no perfil Chrome do Product Hunter

A extensão envia apenas:
- URL atual
- título da página
- sinais visíveis básicos
- indício visual de sessão autenticada

Ela NÃO:
- lê cookie
- lê senha
- envia mensagens
- curte
- comenta
- segue
- compartilha
- salva
- publica
- clica em controles sociais
